# How to Play

## Getting started

1. Run the game (`operation-purge.exe` on Windows, or `cargo run --release`). If Windows warns you, click **More info**, then **Run anyway**.
2. On the New Game screen, press `Enter` to start.
3. You start on the 2D map with the game **paused**. Click one of your (white) robots, then press `F` to take control of it.
4. **Hold** `T` to speed the game up from paused.

If your robot is destroyed, you go back to the 2D map. Pick a new robot to keep playing.

## New Game screen

| Key | Action |
|---|---|
| `Tab` | Switch between the maze and password fields |
| `Left` / `Right` | Change game |
| `Shift` + `Left` / `Right` | Change team |
| `Enter` / `Esc` | OK / Cancel |

Leave the password empty to turn on cheats.

## Driving your robot (3D)

| Key | Action |
|---|---|
| Mouse | Turn (left/right) and aim the barrel (up/down) |
| `E` / `D` | Speed up / slow down |
| Mouse wheel | Set cruise speed |
| Left mouse | Fire bullet |
| Right mouse | Fire rocket |
| `Space` | Fire everything |
| `A` | Go to the 2D map |

## 2D map

| Key | Action |
|---|---|
| Left mouse | Select one of your robots |
| `F` | Take control of the selected robot |
| `S` | Go back to 3D |
| Arrow keys | Move the map |

## Anytime

| Key | Action |
|---|---|
| `T` (hold) / `G` (hold) | Game faster / slower |
| `Q` | Pause |
| `F1` | Show or hide the minimap |
| `F2` | Info |
| `V` | Let the AI drive (with cheats on, take over an enemy robot) |
| `F4` | Restart this game |
| `Esc` | End game |
| `Y` / `N` / `C` | Answer Yes / No / Cancel in pop-ups |
